# Music Vibes

A multi-page website about five music genres (Rap, Pop, R&B, Jazz and Classical), built with HTML and CSS. It was a four-person group project for the Web Design module at Dublin City University in 2025, and I was the team leader.

**Live site:** https://uditharikrishnan.github.io/music-vibes/

## My contribution
- **Home page** (`index.html`): introduction, genre navigation and a card grid linking to each genre
- **Rap section** (`rap.html` and `rappers/`): a genre overview page and five artist profiles (Drake, Kendrick Lamar, Travis Scott, Lil Wayne and Nicki Minaj), each with a biography, key facts, popular songs and a Spotify link
- **Integration:** combining every team member's pages into one site with consistent navigation and a shared stylesheet (`style.css`)

The Pop, R&B, Jazz and Classical sections were built by my teammates.

## Built with
HTML5 and CSS3. There is no framework or build step, so you can open `index.html` in any browser.
